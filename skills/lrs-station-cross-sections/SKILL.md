# 生成桩号点与横断面

## 功能
沿路由按间距生成桩号点，并在每个桩号点处按给定宽度生成垂直于路由的横断面线，适合道路、河道、管线带状成果出图。

横断面按路由法线方向（LOC_ANGLE）左右各延伸「宽度的一半」绘制，因此宽度是断面总长。


## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 输入线要素（名称或路径）
- 路径标识字段
- 站间距（米）
- 横断面宽度（米；左右各一半）
- 输出路径要素类
- 输出桩号点要素类
- 输出横断面要素类

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入线要素> <路径标识字段> <站间距> <横断面宽度> <输出路径要素类> <输出桩号点要素类> <输出横断面要素类>
```
参数说明：

1. 输入线要素
2. 路径标识字段
3. 站间距
4. 横断面宽度
5. 输出路径要素类
6. 输出桩号点要素类
7. 输出横断面要素类
