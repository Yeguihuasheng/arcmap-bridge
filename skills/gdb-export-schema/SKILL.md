# 导出数据集结构清单

## 功能
把要素类/表的字段结构（名称、别名、类型、长度、精度、小数位、是否必填、是否可空、默认值、属性域）导出成 CSV，用于入库前后的结构备案与比对。

与 `gdb-check-schema`（比对两个数据集差异）不同：本技能是**导出单份结构快照**，便于存档和人工核对。


## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 输入要素类或表（名称或路径）
- 输出 CSV 路径

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入要素类或表> <输出 CSV 路径>
```
参数说明：

1. 输入要素类或表
2. 输出 CSV 路径
