# 生成覆盖整条路由的线事件表

## 功能
为每条路由生成一条覆盖全长的线事件表（路径标识 + 起止量测值），用于把线事件定位到路由上。

起止量测值直接取自路由几何的 firstPoint.M / lastPoint.M，因此事件必定覆盖整条路由。


## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 输入路由要素（需先跑 lrs-create-route-by-length 生成）
- 路径标识字段
- 输出事件表（GDB 内表名）

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入路由要素（已带 M 值）> <路径标识字段> <输出事件表>
```
参数说明：

1. 输入路由要素（已带 M 值）
2. 路径标识字段
3. 输出事件表
