# 由河道面提取中心线

## 功能
把河道/湖库水面多边形栅格化后做形态学细化（Thin），得到单像素宽的骨架线再转成矢量线并做 PAEK 平滑，输出河道中心线。用于从水面范围反推深泓线/航道中心线、给河流做纵剖面与里程量算的基准线。

## 算法链路
面 → 栅格化 → Thin 细化（骨架）→ 栅格转线 → PAEK 平滑。

## 使用前提
- 需要 **Spatial Analyst**（Thin）+ **Cartography 许可可用的 SmoothLine**（标准版即可）。
- 像元大小决定精度与耗时：建议 **≤ 河宽/100**（实测：河宽 600m 配 cell 5 时主线约达河长 92%；cell 偏大会缩短主线、增多端部毛刺，属栅格化固有取舍）。
- 多汊河道会输出**多条**中心线（每个连通的水面各一条骨架）。
- 输出线不带原面属性（骨架是派生几何）；需要挂属性可按空间连接。
- 平滑容差过大会把弯道削直，2~5 是经验安全区。

用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 平滑容差给多少？（一般 2~5）
- 中心线输出到哪里？

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <河道面要素（水面/河岸多边形）> <栅格化像元大小（坐标系单位，如米；越小越细但越慢）> <PAEK 平滑容差（一般 2~5，单位同坐标系）> <输出中心线要素>
```
参数说明：

1. 河道面要素（水面/河岸多边形）
2. 栅格化像元大小（坐标系单位，如米；越小越细但越慢）
3. PAEK 平滑容差（一般 2~5，单位同坐标系）
4. 输出中心线要素
