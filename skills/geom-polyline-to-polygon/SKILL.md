# 闭合线转面

## 功能
把闭合的线要素转成面要素类，保留原始坐标系，常用于把 CAD 导入的闭合多段线、地类界线转成图斑面。

**前提**：输入的线应闭合（首尾点重合或接近）。未闭合的线转出的面会被自动闭合，几何可能不符合预期，建议先用 geom-check 体检。


## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 输入线要素类（名称或路径）
- 输出面要素类
- 输入的线是否已闭合（未闭合需先处理）

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入线要素类> <输出面要素类>
```
参数说明：

1. 输入线要素类
2. 输出面要素类
