# 沿线等间距生成点

## 功能
把线要素先转成路由，再按等间距（桩距）沿路由生成点要素类，同时输出路由要素类，适合生成里程桩、采样点。

输出点带 LOC_ANGLE 角度字段（路由法线方向），可直接用于后续横断面生成。


## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 输入线要素（名称或路径）
- 路径标识字段
- 站间距（米，默认 100）
- 输出点要素类
- 输出路径要素类

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入线要素> <路径标识字段> <站间距（默认 100）> <输出点要素类> <输出路径要素类>
```
参数说明：

1. 输入线要素
2. 路径标识字段
3. 站间距（默认 100）
4. 输出点要素类
5. 输出路径要素类
