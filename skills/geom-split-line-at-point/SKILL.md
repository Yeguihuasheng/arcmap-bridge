# 用点打断线

## 功能
把落在（或贴近）线上的点作为断点，把线在断点处切分成多段，属性保留到每一段。用于把道路在交叉口/门牌点处打断、管线在桩号点处断开、河流在监测断面处切开。

## 使用前提
- 容差默认 0：点必须严格落在线上（可用「要素转点/折点转点」或捕捉生成断点保证精度）。
- 一个点只打断它最近的那一段；一条线被多个点逐次切开，输出段数 = 有效断点数 + 1。
- 线端点处的断点、落到线上的重复点会自动忽略。
- 输入线的全部属性会复制到每一段（建议输出到 GDB；输出 shp 时字段名会截 10 字符）。
- 断点在多部件线上只切它贴着的那一部件。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 要打断的线要素是哪个？
- 断点要素是哪个？
- 打断结果输出到哪里？
- 点离线多远还算"在线上"？（给容差如 0.5 Meters；要求严格落在线上填 #）

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入线要素> <断点要素> <输出打断后的线要素> <点吸附容差（点离线小于该值视为在线上；填 # 表示必须严格落在线上）>
```
参数说明：

1. 输入线要素
2. 断点要素
3. 输出打断后的线要素
4. 点吸附容差（点离线小于该值视为在线上；填 # 表示必须严格落在线上）
