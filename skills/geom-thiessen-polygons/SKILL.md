# 生成泰森多边形

## 功能
为每个点生成最近邻分配面（泰森/Voronoi 多边形）：面内任意位置到本点的距离都比到其它点近。用于服务区划分、站点影响范围、监测点位覆盖分区。

## 使用前提
- 直接调用原生 Create Thiessen Polygons，**属性全部保留**。
- 重合的点只生成一个面；输出面数 = 不重合点数。
- 泰森面只在点的**外包范围**内生成，边缘不外扩；想覆盖整个行政区，先给行政区面加密边界点，或对结果做裁剪/外扩。
- Pro 版原实现走 scipy 的 Voronoi（50000 点上限），ArcMap 版改用原生 GP 工具，规模上限由工具自身决定。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

```bat
python scripts\run.py <输入点要素> <输出泰森面要素>
```

2. 输出泰森面要素
