# 逐点划分流域（自动吸附汇流点）

## 功能
对每个输入点：先在给定搜索半径内把点吸附到**汇流累积最大**的像元上（Snap Pour Point），再用 D8 流向栅格圈出该点的上游汇水范围，输出每个点一个流域面。可选用地类栅格统计每个流域内各地类的面积。用于水库/堰坝控制流域、排污口上游范围划分。

## 使用前提
- 需要 **Spatial Analyst**；流向栅格必须是 D8 法生成的（`hydro-flowdir-d8` 的产物即 D8）。
- **编号字段必须是整型**（LONG/SHORT）：它的值会作为流域编号写进输出面的 `WS_ID` 字段。
- 吸附半径建议给一个像元尺寸以上；给太小点容易落在线状河道边上导致流域偏小，给太大可能吸到别的河道。
- 地类统计用 TabulateArea：输出会多出每个地类值一个字段（字段名 = 地类值），输出请用 **GDB**（shp 字段名不允许纯数字）。
- 两个点吸附到同一像元时只输出一个流域。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 出水口点要素是哪个？
- 点编号字段是哪个？（必须是整数型字段）
- 汇流累积栅格在哪？（hydro-flowdir-d8 生成）
- D8 流向栅格在哪？
- 吸附半径给多少？（点吸附到附近最大汇流像元的距离，如 100 表示 100 米）
- 要不要统计每个流域的地类面积？（要就给整型地类栅格，不要填 #）
- 输出流域面到哪里？

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入点要素（出水口/堰坝位置）> <点编号字段（必须是整数字段，值会写进流域面）> <汇流累积栅格（hydro-flowdir-d8 的产物）> <D8 流向栅格（hydro-flowdir-d8 的产物）> <吸附搜索半径（如 100 或 100 Meters）> <地类栅格（可选，整型；填 # 跳过面积统计）> <输出流域面要素>
```
参数说明：

1. 输入点要素（出水口/堰坝位置）
2. 点编号字段（必须是整数字段，值会写进流域面）
3. 汇流累积栅格（hydro-flowdir-d8 的产物）
4. D8 流向栅格（hydro-flowdir-d8 的产物）
5. 吸附搜索半径（如 100 或 100 Meters）
6. 地类栅格（可选，整型；填 # 跳过面积统计）
7. 输出流域面要素
