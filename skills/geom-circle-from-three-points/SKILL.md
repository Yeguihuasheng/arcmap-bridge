# 三点定圆

## 功能
对点要素类每三个点求一个外接圆（圆心 + 半径），输出圆面要素类，可选输出圆心点要素类。

**约束**：输入必须是点要素类；要素总数必须是 3 的倍数（按顺序每三个一组）；三点共线的组会被跳过并提示。

半径取自该组第一个点到圆心的距离。


## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 输入点要素类（名称或路径）
- 要素总数是否为 3 的倍数（不是则先筛选）
- 输出圆面要素类
- 是否同时输出圆心点要素类（是/否）

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入点要素类> <输出圆面要素类> <输出圆心点要素类（可空）>
```
参数说明：

1. 输入点要素类
2. 输出圆面要素类
3. 输出圆心点要素类（可空）
