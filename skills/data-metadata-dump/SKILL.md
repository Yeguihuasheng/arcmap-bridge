# 跨目录递归盘点要素类与字段结构

## 功能
递归扫一个根目录（含嵌套的 .gdb / .mdb / .shp），把找到的每个要素类登记成一张要素级表（路径、名称、几何类型、要素数、坐标系、四至范围），再逐字段登记成一张字段级表（别名、类型、长度、精度、小数位、是否可空、是否必填）。两张 CSV 用 UUID 关联，用于接手陌生数据时的整体盘库与结构备案。

## 输出
- `{前缀}_features.csv`：要素级，每行一个要素类 —— 路径、名称、所在库、几何类型、要素数、坐标系名、XMin/YMin/XMax/YMax、是否可正常读取。
- `{前缀}_schema.csv`：字段级，每行一个字段 —— 所属要素类、字段名、别名、类型、长度、精度、小数位、是否可空、是否必填、默认值。
- 两张表用 `FEAT_UUID` 关联。

## 使用前提
- 只递归**目录树**，不会去连 SDE；SDE 里的要素类要用 `gdb-inventory-csv`。
- 读不出来的要素类会在 `READABLE` 列标 `False` 并跳过，不会中断整批。
- 要素数是逐个 `GetCount` 统计的，要素类很多时耗时较长。
- 与 `gdb-inventory-csv` 的分工：后者只做一个工作空间的一级清单，本技能做**跨目录递归 + 要素数 + 坐标系 + 字段级结构**。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 要扫描哪个根目录？（递归含子目录）
- 结果 CSV 输出到哪个目录？文件名前缀用什么？
- 只想扫哪几种数据源？（.shp / .gdb / .mdb，全扫就填 #）
- 只想扫哪几种要素类型？（Polygon / Polyline / Point 等，全扫就填 #）

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <要递归扫描的根目录> <输出 CSV 的目录> <输出文件名前缀（默认 metadata_dump）> <数据源类型，分号分隔（.shp;.gdb;.mdb；填 # 表示全部）> <要素类型，分号分隔（Polygon;Polyline;Point；填 # 表示全部）>
```
参数说明：

1. 要递归扫描的根目录
2. 输出 CSV 的目录
3. 输出文件名前缀（默认 metadata_dump）
4. 数据源类型，分号分隔（.shp;.gdb;.mdb；填 # 表示全部）
5. 要素类型，分号分隔（Polygon;Polyline;Point；填 # 表示全部）
