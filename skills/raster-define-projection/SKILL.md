# 文件夹栅格批量定义坐标系

## 功能
遍历一个文件夹里的全部栅格，统一定义坐标系（只改元数据不重采样）。用于下载/导出的影像与 DEM 批量挂坐标系。注意：这是「定义」不是「投影」，坐标系本来就对的才能用。

## 使用前提
- **定义 ≠ 投影**：只改元数据。如果栅格坐标本来就是别的坐标系，请用「投影栅格」重采样，否则位置会错。
- 已有坐标系的栅格也会被**覆盖**定义；运行会逐个列出原来是否带坐标系。
- 只处理文件夹第一层的栅格，不递归子目录。
- 常用代码：CGCS2000 经纬度 4490 / CGCS2000 3 度带（如 4521-4553）/WGS84 经纬度 4326 / Web 墨卡托 3857。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 栅格在哪个文件夹？（只处理该文件夹第一层的栅格）
- 要定义成哪个坐标系？（给 EPSG 代码如 4490，或 .prj 文件路径，或 WKT 字符串）

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <栅格所在文件夹（只处理第一层）> <坐标系：工厂代码（如 4490）/ .prj 文件路径 / WKT 字符串>
```
参数说明：

1. 栅格所在文件夹（只处理第一层）
2. 坐标系：工厂代码（如 4490）/ .prj 文件路径 / WKT 字符串
