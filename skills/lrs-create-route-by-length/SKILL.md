# 按长度创建路径（Route）

## 功能
把线要素按线长生成带量测值 M 的路由要素类，同一路径标识的线合并为一条路由，是线性参考分析的第一步。

**前提**：输入应为单部件简单线；同一路径标识下的线数字化方向需一致，否则量测值会反向。


## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 输入线要素（名称或路径）
- 路径标识字段（同值的线会合并成一条路由）
- 输出路径要素类（GDB 内）
- 输入是否已打散为单部件（如未打散，先跑 geom-explode-repair）

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入线要素> <路径标识字段> <输出路径要素类>
```
参数说明：

1. 输入线要素
2. 路径标识字段
3. 输出路径要素类
