# 按重叠面积比例分摊属性（面积加权）

## 功能
把参照图层的数值属性按「重叠面积占参照图斑面积的比例」分摊到每个输入面要素上：输入面压住参照图斑多大比例，就拿多大比例的属性值，多块重叠求和。典型用法：把以行政区统计的人口/指标按面积加权摊到网格或地块上。

## 计算口径
`分摊值 = Σ (参照字段值 × 重叠面积 / 参照图斑总面积)`，对每个输入面求和。面积只参与**比例**计算，单位不影响结果。

## 使用前提
- 输入与参照坐标系必须一致。
- 与任何参照面都不相交的输入面，分摊值为 0（要素保留，不剔除）。
- 分摊字段须为数值型；文本字段请先转数值。
- 输出 = 输入面的完整拷贝 + 每个分摊字段一个同名字段（与输入原有字段重名时自动加 `AP_` 前缀）。建议输出到 GDB。
- 这是**面积加权插值**的简化：默认属性在参照面内均匀分布。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 输入面（网格/地块）是哪个？
- 参照面（带统计值的行政区等）是哪个？
- 分摊哪些字段？（可多个，分号分隔，须是参照面的数值字段）
- 输出到哪里？

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入面要素（接收分摊值的网格/地块）> <参照面要素（带数值属性，如人口）> <要分摊的数值字段（多个用分号分隔）> <输出面要素（输入 + 分摊值字段）>
```
参数说明：

1. 输入面要素（接收分摊值的网格/地块）
2. 参照面要素（带数值属性，如人口）
3. 要分摊的数值字段（多个用分号分隔）
4. 输出面要素（输入 + 分摊值字段）
