# 按分组求组内最近要素距离

## 功能
按一个或多个分组字段把输入要素拆成若干组，逐组只在本组内做近邻分析，把最近要素的 OID、距离、来源图层写回输入要素。用于"同村内各图斑到最近居民点的距离""同流域内各站点到最近水文站的距离"这类必须限定在同组内部比较的场景。

## 使用前提
- 需要 **ArcGIS Desktop Advanced（ArcInfo）** 许可（`arcpy.Near_analysis` 的限制）。
- **会直接改输入要素**：新增 `NEAR_OID`（最近要素的 OBJECTID）、`NEAR_DISTN`（距离）、`NEAR_FCLS`（最近要素来自哪个图层）三个字段。跑之前先备份，或先复制一份再跑。
- 分组字段同时要在近邻要素里存在，否则该组选不中任何近邻要素，结果为空。
- 数据是地理坐标系（经纬度）时 `NEAR_DISTN` 的单位是**度**，需要先投影到投影坐标系再跑才有米制距离。
- 组数很多时是逐组选集 + 逐组 Near，耗时随组数线性增长。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 输入要素是哪个？（注意：结果字段会直接写回它，建议先备份）
- 按哪个/哪些字段分组？（多个用分号分隔）
- 要在哪些要素里找最近的？（可多个，分号分隔）
- 要不要限制搜索半径？（不限就填 #）

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入要素（会被原地写入结果字段）> <分组字段（多个用分号分隔）> <近邻要素（多个用分号分隔）> <搜索半径（可选，留空或 # 表示不限）>
```
参数说明：

1. 输入要素（会被原地写入结果字段）
2. 分组字段（多个用分号分隔）
3. 近邻要素（多个用分号分隔）
4. 搜索半径（可选，留空或 # 表示不限）
