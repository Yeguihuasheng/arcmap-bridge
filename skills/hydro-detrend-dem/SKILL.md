# DEM 河谷趋势面剥离（去趋势）

## 功能
用河谷中心线的高程做 IDW 插值得到「河谷纵向趋势面」，再做圆形邻域平滑，最后从 DEM 里减掉趋势面，得到**去趋势 DEM**（相对河谷底面的高度）。用于剥离河道整体纵坡，突出河床与滩地的局部起伏，是水面范围提取的前置步骤。

## 算法链路
河流线折点 → numpy 采样高程 → IDW 插值趋势面 → 圆形邻域平滑 → DEM − 趋势面。

## 使用前提
- 需要 **Spatial Analyst**（Idw/FocalStatistics/Minus）。
- 河流线要有足够的折点密度（约等于 DEM 像元间距），太稀会插出平直趋势面；必要时先用 densify 加密。
- 输出值 ≈ 相对河谷底面的高度：河道内接近 0，滩地/阶地为正。
- 平滑半径控制趋势面的「纵向平滑度」：大半径保留长波纵坡，小半径会把局部起伏也吸进趋势面。
- 与 `hydro-water-surface-extent` 配套：对去趋势 DEM 给一个高度阈值即可圈水面/滩地范围。

- 河谷中心线（河流线）是哪个？
- 趋势面平滑半径给多少个像元？（一般 30~50）
- 去趋势 DEM 输出到哪里？

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入 DEM 栅格> <河谷中心线（河流线）> <趋势面圆形平滑半径（像元数，一般 30~50）> <输出去趋势 DEM 栅格>
```
参数说明：

1. 输入 DEM 栅格
2. 河谷中心线（河流线）
3. 趋势面圆形平滑半径（像元数，一般 30~50）
4. 输出去趋势 DEM 栅格
