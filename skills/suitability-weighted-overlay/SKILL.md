# 加权叠加适宜性评价

## 功能
按一张准则表把多个栅格（坡度、距离道路、辐射量、地类等）分别重分类到统一分值，再按权重加权求和得到适宜性栅格；可按"排除栅格 + 排除规则"扣掉禁建区，并按最低分值与最小连片像元数圈出候选地块。用于光伏选址、设施农用地选址、公共服务设施布点等"多因子打分"场景。

## 准则表 CSV 格式
每行 5 列，**不要表头**：

```
坡度,D:\\data\\slope.tif,range,0 5 5;5 15 3;15 90 1,0.3
距道路,D:\\data\\dist_road.tif,range,0 500 5;500 2000 3;2000 99999 1,0.2
地类,D:\\data\\landuse.tif,value,11 1;12 2;21 4;22 5,0.5
```

- 类型 `range`：规则每项是 `下限 上限 分值`，区间要连续、从最小值排到最大值；分值越高表示越适宜。
- 类型 `value`：规则每项是 `原值 分值`，未列到的值会被分到 NODATA（相当于排除）。
- 权重可以是任意正数，脚本内部**不做归一化**，最终分值 = Σ(分值 × 权重)。想让结果落在 1~5 就自己把权重配成和为 1。

## 使用前提
- 需要 **Spatial Analyst** 扩展许可。
- 所有输入栅格必须**同一范围、同一像元大小、同一坐标系**，否则加权求和会按范围交集裁剪，结果范围与预期不符。
- 排除规则支持 `>`（大于阈值排除）和 `=`（等于某些值排除），多个条件用分号连接，例如 `>15;=11;=12`。
- 圈选候选地块用的是 8 邻域连片（RegionGroup EIGHT）。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 准则表 CSV 在哪？每行「名称,栅格路径,类型(range/value),重分类规则,权重」，确认内容给全
- 各因子的权重分别是多少？（会写进准则表第 5 列，需逐项确认）
- 有没有必须排除的禁建区？（有就给排除栅格 + 排除规则，例如坡度 >15 或地类 =11）
- 适宜性栅格输出到哪里？
- 要不要圈出候选地块？要的话最低分值和最小连片像元数各是多少？输出到哪里？

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <准则表 CSV（名称,栅格路径,类型 range/value,重分类规则,权重）> <输出适宜性栅格> <排除栅格（可选，填 # 跳过）> <排除规则（可选，如 >15 或 =11;=12；填 # 跳过）> <候选地块最低分值（可选，填 # 跳过圈选）> <候选地块最小连片像元数（默认 9）> <输出候选地块面要素（可选，填 # 跳过）>
```
参数说明：

1. 准则表 CSV（名称,栅格路径,类型 range/value,重分类规则,权重）
2. 输出适宜性栅格
3. 排除栅格（可选，填 # 跳过）
4. 排除规则（可选，如 >15 或 =11;=12；填 # 跳过）
5. 候选地块最低分值（可选，填 # 跳过圈选）
6. 候选地块最小连片像元数（默认 9）
7. 输出候选地块面要素（可选，填 # 跳过）
