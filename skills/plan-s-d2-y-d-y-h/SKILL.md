# 三调转用地用海

## 功能
三调转用地用海。

## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：
- 输入图层/表（名称或路径）
- 目标字段（若涉及属性写入）
- 关键算法参数（单位/分级/阈值）
- 输出位置（GDB 要素类 / xlsx 路径）
- 坐标系要求：沿用当前工程

**原窗体参数项**（提取自界面定义，作问询参照）：输入三调图层： ／ 输出用地用海名称字段： ／ 版本：

**界面固定选项**：一对多的转为【待细分】 ｜ 一对多的转为一级类 ｜ 全部转为一级类

## 执行路径（ArcMap 版）
本技能经 **yghsBridge ArcMap 桥接**执行：AI 按上方问询清单逐项确认参数后，
把参数代入执行脚本 `scripts/run.py`，经桥的 `execute_code` 通道（py2.7 arcpy）在 ArcMap 内执行。

脚本用法：
```
run.py <图层> <三调名称字段DLMC> <目标字段> <转换类型:通用|待细分转一级类|全部转一级类> <版本:旧版|新版>
```

执行完成后读回输出行数/抽查字段值/确认成果文件非空。

## 原始实现要点（参考，源自 Pro 版）
**源码**：完整随附于本技能目录——`source/SD2YDYH.xaml`、`source/SD2YDYH.xaml.cs`

**算法**：三调（DLMC 名称）→ 用地用海（目标字段），靠**新旧两版映射 Excel**（resources/ 内两份）：
1. CheckData 校验图层与 DLMC 字段；
2. 转换类型三选一：`通用` / `待细分转一级类` / `全部转一级类`（对应映射表里的 3 个 sheet）；
3. 版本二选一：`旧版`→三调用地名称_to_用地用海用地名称.xlsx；`新版`→…_新版.xlsx；
4. 复制映射表到工程 Home 文件夹 → AttributeMapper(in_data, "DLMC", map_field, sheet) 逐行替换；
5. 删除临时 xlsx。


**依赖资源**：已复制到本技能 `resources/` 子目录（2 份）。
