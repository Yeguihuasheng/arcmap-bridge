# 按出口面划分汇水区

## 功能
由 DEM 算 D8 流向，再以一个或多个**出口面**（洼地、库塘、研究区边界开口等面要素）为倾泻点划分汇水区，输出每个出口对应的集水多边形。用于小流域/汇水单元快速圈定。

## 使用前提
- 需要 **Spatial Analyst**。
- DEM 建议先填洼（`hydro-flowdir-d8` 一次产填洼/流向/累积），否则真洼地会截断汇水。
- 输出面带 `gridcode` 字段，值 = 出口面在输入里的 OID。
- 与 `hydro-watershed-by-point` 的分工：那个用**点**出水口（可吸附、可带地类统计）；本技能用**面**出口，多出口一次出多个汇水区。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 输入 DEM 是哪个？
- 出口面是哪个图层？（每个面圈一个汇水区）
- 汇水区面输出到哪里？

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入 DEM 栅格> <出口面要素类（每个面 = 一个汇水区出口）> <输出汇水区面要素>
```
参数说明：

1. 输入 DEM 栅格
2. 出口面要素类（每个面 = 一个汇水区出口）
3. 输出汇水区面要素
