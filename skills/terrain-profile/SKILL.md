# 沿线路生成地形剖面

## 功能
沿一条（或一组）线要素在 DEM/表面上采样，生成剖面数据表（每行 = 线上某位置的 X/Y/距起点距离/高程），并可把剖面图导出成图片文件。用于道路纵断面、管线埋深、视线分析的快速取值。

## 使用前提
- 需要 **3D Analyst** 扩展许可（Stack Profile 工具）。
- 剖面表字段：`FIRST_DIST`（距线起点距离）、`FIRST_Z`（高程）、`FIRST_SLINE_ID`（线编号）、`FIRST_Z_REAL`（原始高程）等，以工具实际输出为准。
- 剖面图导出在后台 Python 里可能失败（图形对象依赖桌面会话），失败时表已生成，会提示改在 ArcMap 里手动出图。
- 剖面密度由 DEM 像元决定，线太短可能只采到两三个点。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- DEM 是哪个？
- 剖面线是哪条（哪个线要素）？
- 剖面数据表输出到哪里？
- 要不要把剖面图导成图片？要就给文件路径（.jpg/.png），不要填 #

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <表面栅格（DEM）> <剖面线要素> <输出剖面数据表（GDB 表或 CSV 均可）> <剖面图导出文件（如 .jpg/.png；填 # 只要表不要图）>
```
参数说明：

1. 表面栅格（DEM）
2. 剖面线要素
3. 输出剖面数据表（GDB 表或 CSV 均可）
4. 剖面图导出文件（如 .jpg/.png；填 # 只要表不要图）
