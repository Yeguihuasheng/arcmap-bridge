# 多环缓冲（含负值内缩）

## 功能
按一组距离（如 100;200;500，支持负值=面向内收缩）逐个生成缓冲，每环的距离写进 DIST 字段，最后合并成一个面要素类。用于圈层分析（0-100 / 100-200 / 200-500 影响带）、由近及远的设施辐射分级，负距离可做面内核/边缘带。

## 输出结构
每个距离生成一环，全部叠加进一个要素类，`DIST` 字段记录该要素属于哪一环（负值=内缩环）。要看"圈层带"（0-100、100-200）自己做相邻环擦除。

## 使用前提
- 距离单位 = 坐标系单位；投影坐标系下 100 = 100 米，地理坐标系（经纬度）下是**度**，建议先投影。
- 面要素负距离会收缩；距离绝对值大于面尺寸时该面会消失（属正常）。
- 与 `plan-setback-buffer` 的分工：那个做规划红线单距离退让带，本技能做多环圈层；与 `geom-inside-buffer` 的分工：那个只做单宽内侧环带。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 输入要素是哪个？
- 各环的距离是多少？（分号分隔，如 100;200;500；负值表示向内收缩）
- 输出多环面到哪里？
- 每环缓冲要不要按字段融合？（ALL=同字段值融合成一个环；NONE=保留全部要素）

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入要素（点/线/面）> <缓冲距离列表，分号分隔（如 100;200;500；负值=向内收缩）> <输出多环面要素> <融合字段（分号分隔；填 NONE=不融合只叠环；填 ALL=全部融合）>
```
参数说明：

1. 输入要素（点/线/面）
2. 缓冲距离列表，分号分隔（如 100;200;500；负值=向内收缩）
3. 输出多环面要素
4. 融合字段（分号分隔；填 NONE=不融合只叠环；填 ALL=全部融合）
