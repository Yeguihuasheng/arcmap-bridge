# 河网按河段整编成河流线

## 功能
把人工编辑过的河网（已删掉不分析的支流、ReachName 已填好）按 ReachName 融合成一条河段一根线，再做 PAEK 平滑，产出干净的 flowline 河流线。是纵剖面/横断面分析的基础线。

## 使用前提
- 河网必须先人工编辑：删掉不分析的支流，`ReachName` 字段按河段填唯一值。
- 融合时共享端点的线会并成一条；平滑容差过大会把弯道削直。
- 输出 `{要素数据集}\flowline`。
- 与 `tool-dissolve-fields` 的分工：那个融合面并拼接文本清单；本技能融合线 + 平滑，是河流业务整编。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 成果放进哪个要素数据集？
- 河网要素类是哪个？（支流要先手工删好、ReachName 要填好）
- 平滑容差给多少？（一般 2~5）

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输出要素数据集（成果放这里）> <编辑好的河网要素类（带 ReachName 字段）> <PAEK 平滑容差（2~5 经验安全区，坐标系单位）>
```
参数说明：

1. 输出要素数据集（成果放这里）
2. 编辑好的河网要素类（带 ReachName 字段）
3. PAEK 平滑容差（2~5 经验安全区，坐标系单位）
