# 识别地形洼地

## 功能
用「填洼 — 与原高程相减」的方法在 DEM/水深栅格上识别洼地，按 z 限差与面积阈值过滤后输出洼地面要素类，可用于水库库容、内涝点、采坑排查。

**依赖**：需要 Spatial Analyst 扩展许可（脚本会自动检出/归还）。

流程：`Fill(z_limit)` → `Minus(原栅格, 填洼栅格)` → 取负值区重分类 → 转面 → 按面积区间过滤（下限 = 3 倍 cell size 的平方，上限 = 你给的最大面积）。

原实现面向**水深（全负值）**数据，对常规 DEM 同样成立：洼地处差值恒为负。


## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 输入高程/水深栅格（路径）
- 填洼 z 限差（与栅格高程单位一致）
- 洼地最大面积（平方米）
- 输出洼地面要素类
- 是否已具备 Spatial Analyst 扩展许可

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入高程/水深栅格> <填洼 z 限差（超过该深度不算洼地）> <洼地最大面积（平方米）> <输出洼地面要素类>
```
参数说明：

1. 输入高程/水深栅格
2. 填洼 z 限差（超过该深度不算洼地）
3. 洼地最大面积（平方米）
4. 输出洼地面要素类
