# 横断面线生成测点（带高程采样）

## 功能
把每条横断面线按指定间距加密成测点，输出带断面编号、距左岸起点距离、平面坐标的测点要素；给 DEM 时每个测点自动采样高程写进 Z 字段。用于河床断面测量布点、断面形态与冲淤分析的基础数据。

## 输出字段
`SEQ`（断面编号，取自编号字段）、`DIST`（距断面左端起算的距离）、`POINT_X/POINT_Y`（坐标）、`POINT_Z`（高程，给了 DEM 才有值）。

## 使用前提
- **断面线方向约定从左岸起画**（起点=左岸）；画反了 DIST 会镜像，在编辑里 flip 翻转即可。
- 编号字段值会原样写入 SEQ（文本/数值均可）。
- 每条断面首尾各强制一个点（间距除不尽时末点=终点，不会丢）。
- 高程采样用 numpy 读 DEM 像元中心值：测点落在 NoData 上 Z 为空。
- 与 `lrs-station-cross-sections` 的分工：那个**生成**桩号与横断面线，本技能在**已有**断面线上加密测点并采高程。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 横断面线是哪个？
- 断面编号字段是哪个？（每条断面一个唯一编号）
- 测点间距多少米？
- 要不要采样高程？（要就给 DEM，不要填 #）
- 测点输出到哪里？

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入横断面线要素> <断面编号字段（每个断面唯一，如 Seq/断面号）> <测点间距（线坐标系单位，如米）> <DEM 栅格（可选，填 # 不采高程）> <输出测点要素>
```
参数说明：

1. 输入横断面线要素
2. 断面编号字段（每个断面唯一，如 Seq/断面号）
3. 测点间距（线坐标系单位，如米）
4. DEM 栅格（可选，填 # 不采高程）
5. 输出测点要素
