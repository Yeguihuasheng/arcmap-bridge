# 生成经纬网（标准分幅格网）

## 功能
按给定范围与间隔（度）生成经纬网线：南北向经线 + 东西向纬线，每条线带方向类型与度分秒（DMS）标注字段。用于标准分幅图框、区位索引图、制图底图的坐标网。

## 输出结构
每条线一个要素，字段：`LINE`（`E-W` 纬线 / `N-S` 经线）、`DMS`（度分秒标注，如 `112°30'00"E`）、`DEG`（十进制度值）。坐标系固定 **WGS84（EPSG:4326）**。

## 使用前提
- 范围来源是图层时自动投影到 WGS84 取范围；手给四个数必须是 WGS84 经纬度（x=经度 y=纬度）。
- 间隔按度：5 分 = 0.0833，30 分 = 0.5，分幅图 1:1 万常用 5 分。
- 范围边缘不足一个间隔的线也会生成（起点按 interval 向下取整对齐）。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 格网范围按哪个图层取？（或直接给 WGS84 的 xmin ymin xmax ymax 四个数）
- 格网间隔多少度？（常见 0.0833=5分 / 0.5=30分 / 1 / 10）
- 格网线输出到哪里？

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <范围来源：图层路径，或 xmin ymin xmax ymax（WGS84 经纬度）> <格网间隔（度，如 0.5 / 1 / 10）> <输出格网线要素（WGS84）>
```
参数说明：

1. 范围来源：图层路径，或 xmin ymin xmax ymax（WGS84 经纬度）
2. 格网间隔（度，如 0.5 / 1 / 10）
3. 输出格网线要素（WGS84）
