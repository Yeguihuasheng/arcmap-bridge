# 用切割线切分要素

## 功能
用一条（或多条）切割线把面/线要素切开，输出切割后的所有碎片，原属性复制到每块。用于按规划界线、道路中心线、河流界线切分地块/图斑，比手工裁剪快且不丢属性。

## 使用前提
- 切割线必须**横贯**目标要素（两端都要超出要素边界），只搭在内部一段切不开（arcpy cut 的机制）。
- 多条切割线会逐条递归切分，n 条线最多切出 n+1 块。
- 与切割线不相交的要素原样通过。
- 切割面属性复制到每块；输出建议 GDB。
- 与 `geom-split-line-at-point` 的分工：那个用**点**打断**线**，本技能用**线**切**面/线**。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 要切分的面/线要素是哪个？
- 切割线是哪个（哪个线要素）？
- 切分结果输出到哪里？

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入面或线要素（被切的）> <切割线要素（可多条）> <输出切分结果>
```
参数说明：

1. 输入面或线要素（被切的）
2. 切割线要素（可多条）
3. 输出切分结果
