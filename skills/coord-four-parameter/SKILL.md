# 四参数坐标转换

## 功能
用一组同名控制点（源坐标系与目标坐标系各一套 XY）按最小二乘求平面四参数（平移 DX/DY + 缩放系数 k + 旋转角 θ），并可选地把一个点/线/面要素类按该参数整体转换到目标坐标系。适用于地方独立坐标系与国家坐标系（如 CGCS2000）之间的平面转换，无需栅格投影参数、只要有控制点即可。

## 输出
- 四参数：DX、DY（平移，目标坐标单位）、k（缩放系数）、θ（旋转角，秒）。
- 每个控制点的转换残差与整体 RMSE（中误差），用于判断控制点质量。
- 若指定了要素类，输出转换后的要素类（平面 XY 变换，高程 Z 保留原值）。

## 算法
模型 X' = DX + k·cosθ·X − k·sinθ·Y，Y' = DY + k·sinθ·X + k·cosθ·Y，
化为线性最小二乘（未知数 a=DX, b=k·cosθ, c=k·sinθ, d=DY），
正规方程 4×4 高斯消元求解，无 numpy 依赖。

## 使用前提
- 控制点至少 3 个且不共线，否则正规方程奇异。
- 源/目标坐标均须为平面投影坐标（米）；经纬度请先投影。
- 该四参数是平面相似变换（保角），不包含投影变形修正。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 控制点文件路径？（格式：每行 源X,源Y,目标X,目标Y，至少 3 个不共线点）
- 只求参数，还是要求参数 + 转换某个要素类？
- 若要转换：转换哪个要素类？输出到哪？参数报告写到哪？
- 坐标系约定：源坐标与目标坐标各是什么（用于记录，不影响计算）？

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <控制点文件（UTF-8 或 GBK，每行：源X,源Y,目标X,目标Y）> <要转换的要素类（留空 # 则只求参数不转换）> <转换后要素类路径（apply_fc 为空时此参数忽略）> <参数与残差报告输出 txt 路径>
```
参数说明：

1. 控制点文件（UTF-8 或 GBK，每行：源X,源Y,目标X,目标Y）
2. 要转换的要素类（留空 # 则只求参数不转换）
3. 转换后要素类路径（apply_fc 为空时此参数忽略）
4. 参数与残差报告输出 txt 路径
