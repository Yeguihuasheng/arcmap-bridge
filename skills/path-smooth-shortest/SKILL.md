# 按坡度限制在 DEM 上找最短路径

## 功能
在 DEM 上以「三维实际距离」为代价做 Dijkstra 最短路搜索，相邻像元之间的坡度超过阈值就视为不可通行，输出起点到终点的路径线（可带 Z）。用于选线、巡线、施工便道、管线走向这类"绕开陡坡找最短"的场景。

## 使用前提
- **必须用投影坐标系的 DEM**（单位是米）。地理坐标系（经纬度）下高差与水平距离量纲不一致，坡度算出来没有意义。
- 代价定义：相邻像元走一步的代价 = √(水平距离² + 高差²)，正交步长 = 像元边长，对角步长 = 像元边长 × √2。
- 坡度阈值 `max_slope` 是**比值**不是度数：0.3 = 30% ≈ 16.7°。
- 起点/终点落在 DEM 范围外或落在 NoData 上会直接报错。
- 8 邻域搜索，网格规模建议 **不超过 500 × 500 像元**；更大的 DEM 请先裁出走廊带再跑（ArcMap 自带 32 位 Python，太大会很慢甚至内存不足）。
- 若终点不可达（被陡坡完全包围），会明确提示无路径而不产出空结果。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- DEM 是哪个？
- 起点坐标是多少？（X、Y，要和 DEM 同一坐标系）
- 终点坐标是多少？
- 最大允许坡度是多少？（填 0.3 表示 30%，即每走 100 米最多升/降 30 米）
- 路径线输出到哪里？

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入高程栅格 DEM> <起点 X 坐标（与 DEM 同坐标系）> <起点 Y 坐标> <终点 X 坐标> <终点 Y 坐标> <最大允许坡度（高差/水平距离，如 0.3 表示 30%）> <输出路径线要素类>
```
参数说明：

1. 输入高程栅格 DEM
2. 起点 X 坐标（与 DEM 同坐标系）
3. 起点 Y 坐标
4. 终点 X 坐标
5. 终点 Y 坐标
6. 最大允许坡度（高差/水平距离，如 0.3 表示 30%）
7. 输出路径线要素类
