# 按去趋势高度圈水面范围

## 功能
对去趋势 DEM 取「低于某高度阈值」的连通区域转成面，并做 PAEK 平滑去掉栅格锯齿，输出水面/滩地范围多边形。配合 `hydro-detrend-dem`：阈值 0.5 就是"高出河谷底面 0.5 米以内的淹没范围"。

## 判定规则
去趋势 DEM 值 **≤ 阈值** 的像元划入水面（值越低越接近河谷底）。

## 使用前提
- 需要 **Spatial Analyst**；输入必须是**去趋势 DEM**（直接用原始 DEM 会把整个下游都圈进去，没有意义）。
- 阈值含义 = 高出河谷趋势面的高度：0.3~1 米常对应平滩水面，调大圈得更宽。
- 输出面字段：`VALUE`（原栅格值）；平滑容差 0 则保留栅格锯齿边界。
- 输出建议 GDB；边界想更圆滑可再手动平滑。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 去趋势 DEM 是哪个？（hydro-detrend-dem 的产物）
- 高度阈值给多少？（如 0.5 表示高出河谷底 0.5 米以内）
- 面要不要平滑？（给 PAEK 容差如 2，不平滑填 0）
- 水面范围输出到哪里？

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入去趋势 DEM（hydro-detrend-dem 的产物）> <高度阈值（去趋势值 <= 该值的区域划入水面）> <面平滑容差（0 = 不平滑；一般取 1~2 个像元大小）> <输出水面范围面要素>
```
参数说明：

1. 输入去趋势 DEM（hydro-detrend-dem 的产物）
2. 高度阈值（去趋势值 <= 该值的区域划入水面）
3. 面平滑容差（0 = 不平滑；一般取 1~2 个像元大小）
4. 输出水面范围面要素
