# 把切线烧进 DEM（水文修正）

## 功能
沿切线（culvert/堤防开口线等）把 DEM 高程压到沿线最低值，打通被路堤、坝体挡住的水流路径，产出水文修正后的 DEM。是流域分析前「让水流的过去」的关键预处理。

## 原理
切线栅格化 → 可选像元加宽 → 分区统计取沿线**最低**高程 → 把最低值烧回 DEM（Con 替换切线覆盖的像元）。

## 使用前提
- 需要 **Spatial Analyst**。
- 全部输入同一坐标系；输出像元大小、范围、对齐均与输入 DEM 一致。
- 切线 OID 即烧入区分组，每条切线独立取最小值。
- 输出 `{工作空间}\dem_hydro`，自动建统计与金字塔。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 水文修正后的 DEM 存到哪个 GDB？
- 切线图层是哪个？（应画在所有挡水构筑物的开口位置）
- 输入 DEM 是哪个？切线要加宽几个像元？

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输出工作空间（GDB 路径）> <切线要素类（在堤/坝/路埂开口处画的线）> <输入 DEM 栅格> <切线加宽像元数（0=不加宽，一般 1~3）>
```
参数说明：

1. 输出工作空间（GDB 路径）
2. 切线要素类（在堤/坝/路埂开口处画的线）
3. 输入 DEM 栅格
4. 切线加宽像元数（0=不加宽，一般 1~3）
