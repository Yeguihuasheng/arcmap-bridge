# 按字段融合并拼接文本清单

## 功能
按分组字段融合要素，同时把指定的文本字段值去重拼接成清单（如「甲村;乙村;丙村」）写进结果。解决标准 Dissolve 只能给统计值、把文本清单丢掉的问题：融合一个乡镇面，同时保留它包含的全部村庄名单。

## 输出结构
融合字段保留原值；每个拼接字段在输出里同名（前面加 `CAT_` 前缀避免冲突），值 = 该组内该字段的**去重清单**，按分隔符连接。

## 使用前提
- 拼接字段应为**文本型**（数值型请先转文本，否则清单里全是数字）。
- 清单按出现顺序去重；要素特别多时清单可能很长，GDB 的 TEXT 上限约 2GB 无压力，**输出 shp 时上限 254 字符会被截断**。
- 融合用 SINGLE_PART（同组多部件合成一个要素）；要保留每个图斑请用 `tool-batch-merge` 或原生 Dissolve。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 输入要素是哪个？
- 按哪些字段融合？（分号分隔，如 乡镇名）
- 哪些文本字段要拼成清单？（分号分隔，如 村名;地类）
- 输出融合结果到哪里？
- 清单里各项用什么分隔？（默认分号）

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入要素> <融合字段（分号分隔）> <要拼接清单的文本字段（分号分隔）> <输出融合要素> <清单分隔符（默认 ;）>
```
参数说明：

1. 输入要素
2. 融合字段（分号分隔）
3. 要拼接清单的文本字段（分号分隔）
4. 输出融合要素
5. 清单分隔符（默认 ;）
