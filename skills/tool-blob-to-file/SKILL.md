# BLOB 字段批量导出文件

## 功能
读取要素类 BLOB 字段里的二进制内容（照片、PDF、签名图等），按记录逐条导出成本地文件，文件名取自指定字段值（无该值时用 OID）。用于把外业照片、巡查影像从库中批量落盘整理。

## 使用前提
- BLOB 字段里必须是完整文件字节（不是 Esri 附件表）；若用的是要素附件，请先用「导出附件」工具。
- 文件名会做字符清洗（非法字符转 `_`）；同名会自动加 `_1/_2` 后缀防覆盖。
- 空值记录跳过并计数，不会中断。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 输入要素类/表是哪个？
- BLOB 字段是哪个？
- 用哪个字段的值做文件名？（填 # 就用要素编号）
- 导出到哪个目录？
- 文件扩展名是什么？（默认 .jpg）

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入要素类或表（含 BLOB 字段）> <BLOB 字段名> <文件名字段（取其值做文件名；填 # 用 OID）> <导出目录> <文件扩展名（默认 .jpg）>
```
参数说明：

1. 输入要素类或表（含 BLOB 字段）
2. BLOB 字段名
3. 文件名字段（取其值做文件名；填 # 用 OID）
4. 导出目录
5. 文件扩展名（默认 .jpg）
