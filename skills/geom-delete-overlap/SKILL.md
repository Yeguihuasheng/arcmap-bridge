# 减去与参照图层的重叠部分

## 功能
把输入要素与参照图层重叠的部分从几何上挖掉，输出"输入减去参照"的剩余部分，属性保留。例如从规划范围里挖掉已批红线、从林地图斑里挖掉建设用地。等价于 Erase，但**不需要 Advanced 许可**。

## 使用前提
- 参照图层会先融合成一个整体再逐要素做几何差分，输入与参照坐标系必须一致。
- 与输入完全不重叠的要素原样通过。
- 被完全覆盖的输入要素会变成空几何（保留一条空记录），可按需在 ArcMap 里删除 Shape 为空的行。
- 与 `tool-batch-clip` 的分工：Clip 是**保留**掩膜内的部分，本技能是**挖掉**掩膜内的部分（互补操作）。



## 使用前必须先问询（缺一不可）
用 AskUserQuestion 逐项确认下列参数，全部明确后才执行；不确定的给候选值让用户选：

- 输入要素（被挖的图层）是哪个？
- 参照要素（要挖掉的范围）是哪个？
- 输出剩余部分到哪里？

## 执行路径
直接执行本技能的 `scripts/run.py`（参数按上表顺序传入）。运行环境：ArcMap

## 执行后复核
- 读回输出的行数/字段值或打开结果文件抽查 3 项；
- 报错时看 traceback 定位到具体参数。

## 参数与调用
```bat
python scripts\run.py <输入要素（要被挖的）> <参照要素（挖掉的范围）> <输出剩余要素>
```
参数说明：

1. 输入要素（要被挖的）
2. 参照要素（挖掉的范围）
3. 输出剩余要素
